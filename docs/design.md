# 設計:夜語(浪漫匿名聊天室)

視覺稿:https://claude.ai/artifact/5TDvo5Hjbwu99vBkJpAQzV(私人頁面,僅擁有者可開)
需求見 `docs/requirements.md`,架構見 `docs/architecture.md`。

## 風格

深酒紅夜色的底,配玫瑰粉、香檳金、暖奶油白。標題襯線、訊息氣泡圓潤。手機優先。
名稱「夜語」,英文副標 *whispers under one moon*。

### 色彩

| 用途 | 色碼 |
|---|---|
| 頁面背景 | `#22101C` |
| 面板、側欄、輸入框 | `#2B1625`、`#331A2B` |
| 別人的氣泡、選取列 | `#3D2034` |
| 分隔線與邊框 | `#4A2A40`、`#5A3450` |
| 主要文字 | `#F8E9E4` |
| 次要文字 | `#BFA0A8` |
| 弱化文字(時間、提示) | `#8E6F7D` |
| 主色(玫瑰粉:自己的氣泡、送出鍵、主按鈕) | `#E8869F` |
| 主色上的文字 | `#2A0F1C` |
| 強調(香檳金:標籤、橫幅、新訊息按鈕) | `#D9B27C` |
| 錯誤與提示文字 | `#F4A3B5` |
| 在線小圓點 | `#A8D5BA` |

### 代號顏色
依代號文字雜湊,從這 6 色固定挑一個,同一代號永遠同色:
`#F4A3B5` 玫瑰、`#F6B79A` 蜜桃、`#C3A6E8` 薰衣草、`#A8D5BA` 鼠尾草、`#E8C77C` 金、`#9CC5E8` 天藍。
色塊上的字用 `#2A0F1C`。

### 字體
- 標題:Noto Serif TC(500、700)
- 內文:Noto Sans TC(400、500)
- 英文副標:Cormorant Garamond 斜體 500
- 以上來自 Google Fonts。標題字距拉寬(約 0.15–0.2em)。

### 形狀
輸入框與按鈕為膠囊形(圓角約高度一半)。氣泡圓角 20px,說話者那一側的角收成 4px。圖示一律用線條 SVG(愛心、送出箭頭、離開、關閉),不用 emoji。觸控目標至少 44px。

## 畫面清單

### 1 進入頁(手機 390×844)
- 愛心圖示、「夜語」標題、英文副標、一段說明文字。
- 「你的代號」輸入框(永遠空白,12 字上限)、字數計數「n / 12」。
- 代號重複的錯誤:輸入框邊框變玫瑰粉,下方顯示「這個代號已有人使用,請換一個」。
- 「進入夜語」按鈕。
- 底部小字「訊息不會被保存,離開後就消失了。」

### 2 聊天室:剛進入(手機)
- 頂部列:愛心與「夜語」、「N 人在線」按鈕(開名單)、離開按鈕。
- 歡迎卡片:「歡迎,{代號}」加「目前有 N 人在線,還沒有訊息。說點什麼吧。」有人說話後消失。
- 灰色進出提示:「{代號} 加入了聊天室」。
- 底部輸入列:輸入框、送出鍵、「0 / 500」計數。

### 3 聊天室:聊天中(手機)
- 頂部橫幅(香檳金):「連線中斷,重新連線中…」,斷線時才出現。
- 別人的訊息靠左,顯示代號(依代號上色)和相對時間;自己的訊息靠右,玫瑰粉氣泡,只顯示時間。
- 時間規則:1 小時內用「剛剛」「3 分鐘前」,滿 1 小時改顯示固定時間「14:32」。
- 進出提示:「小滿 加入了聊天室」「晚風 離開了」,置中灰色小字。
- 往上翻舊訊息時,底部浮出「有新訊息 ↓」金色按鈕。
- 送太快或超過字數時,輸入列下方左側顯示一行玫瑰色提示(例「送太快了,請稍等一下」),右側是字數計數。

### 4 線上名單抽屜(手機)
- 從右側滑出,寬 300px,背景壓暗。
- 標題「線上名單」加人數標籤、關閉鈕。
- 依加入先後排列;每列有代號首字圓形頭像和代號文字(同色);自己那列有底色並標「(你)」。
- 底部有「離開聊天室」按鈕。

### 5 電腦版(寬 ≥ 1280)
- 左側為訊息區,右側 280px 常駐名單(內容同 4)。
- 頂部列:標題、英文副標、「你是 {代號}」、「離開」按鈕。
- 訊息區置中,最大寬 720px;氣泡最大寬 70%。
- 輸入框佔位文字提示「Enter 送出,Shift+Enter 換行」。

### 分頁標題(非畫面,是行為)
分頁在背景且有新訊息時,標題顯示 `(3) 夜語`,回到分頁後清除。沒有聲音,也沒有系統通知。

## 響應式
- 手機(窄)用畫面 1–4 的版型:名單收進抽屜,輸入列固定在底部。
- 約 900px 以上切換成畫面 5 的版型:名單常駐右側。
- 輸入列要避開手機鍵盤。

## 實作備註
- 設計稿是靜態的,沒有互動。狀態(錯誤、斷線、有新訊息、抽屜開關)在實作時由 `ui.js` 切換。
- 設計稿的假資料(月光、星河、小滿、晚風)只是示意,實作前端階段由 `transport-mock.js` 提供類似的模擬資料。
- 訊息文字一律用 `textContent` 渲染,不解析 HTML,網址不轉連結。
- 設計稿裡有兩個稿面上加的小東西:進入頁底部的「訊息不會被保存」,以及電腦版標題旁的英文副標,可保留。
