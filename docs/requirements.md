# 需求:匿名聊天室

## 是什麼
不用登入的匿名聊天室。所有人在同一個聊天室。任何知道網址的人都能用,電腦和手機都要好用。

## 使用者會看到什麼、做什麼

**進入與離開**
- 輸入代號後進入。輸入框永遠是空白,一定要自己打。代號限 12 字,不可與線上的人重複,重複時提示換一個。
- 重新整理或斷線重連時,直接回到聊天室並沿用原代號。若原代號已被別人使用,退回進入頁。
- 聊天室有「離開」按鈕。按下後回到進入頁,不會自動回來。

**聊天室畫面**
- 剛進來看到歡迎提示(含目前在線人數),有人說話後消失。
- 不保留歷史訊息,只看得到加入之後的訊息。
- 每個代號依名稱配固定顏色,訊息和名單一致。
- 時間:1 小時內用相對時間(剛剛、3 分鐘前),滿 1 小時改顯示固定時間(14:32)。
- 線上名單依加入先後排列,自己標「(你)」,顯示總人數。
- 有人進出時,訊息串中間顯示灰色提示。
- 斷線時頂部顯示重新連線中。
- 分頁在背景時,標題顯示未讀數(如「(3) 匿名聊天室」),回來後清除。沒有聲音,也沒有系統通知。

**發訊與防護**
- 單則 500 字、每人每秒最多一則。
- 訊息一律當純文字,網址不會變成連結。
- Enter 送出,Shift+Enter 換行。

## 不做
註冊、登入、歷史訊息、檢舉或踢人、敏感字過濾、聲音與系統通知。

## 開發順序
先做前端並放上 GitHub Pages,最後才接 Supabase。
